# Alzheimer's Disease Classification

## Overview
This project uses machine learning to classify Alzheimer's-related diagnosis categories using patient demographic, cognitive assessment, and brain measurement data.

## Dataset
The dataset contains information from three sources:
- **Diagnosis:** Patient diagnosis labels.
- **Cognitive Scores:** Cognitive assessment measurements.
- **Data:** Demographic and brain-related measurements.

The datasets are combined using the `RID` patient identifier.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Jupyter Notebook

## Machine Learning Approach
- Data cleaning and preprocessing
- Handling missing values
- Categorical feature encoding
- Train-test splitting
- Random Forest classification
- Model evaluation using accuracy, classification report, and confusion matrix

## Diagnosis Categories
- CN
- AD
- EMCI
- LMCI
- SMC

## Project Objective
To explore how machine learning can classify Alzheimer's-related diagnostic categories using structured patient data.
